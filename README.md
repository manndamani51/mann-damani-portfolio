# Mann Damani — Portfolio

A responsive personal portfolio built with plain **HTML, CSS and JavaScript**.

## Included
- Responsive desktop / tablet / mobile layout
- Sticky navigation with mobile menu
- Scroll progress indicator
- Reveal-on-scroll animations
- Accessible reduced-motion support
- Hero section with profile photo
- About, Skills, Experience, Projects, Education and Contact sections
- Resume link
- LinkedIn and GitHub links
- No framework or build step required

## Run locally

1. Extract the folder.
2. Open `index.html` in a browser.

For the best development experience, open the folder in VS Code and use the **Live Server** extension.

## Before publishing

The resume supplied with the portfolio contains LinkedIn and GitHub profile links, but no individual repository URLs for the two projects. The project buttons therefore currently point to the GitHub profile.

Replace each project link in `index.html` with its exact repository URL when available.

The portfolio uses Google Fonts and Font Awesome from CDNs. If you want a completely offline version, download and self-host those assets.

## Deploy

This static site can be deployed to GitHub Pages, Netlify, Vercel or any standard static hosting service.
